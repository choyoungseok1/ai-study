## 오늘 한 것
- `code/week03/pg_lv1_025.py`: 프로그래머스 Lv.1 기사단원의 무기 문제 — 1~number 각 숫자의 약수 개수를 구해 공격력으로 사용, limit 초과 시 power로 대체하여 총 철 무게(합) 계산. √n 약수 카운팅 기법 적용 (i²≤n까지만 탐색, 짝 약수 count+=2, 완전제곱이면 -1)

## 배운 개념
- **약수 개수 O(√n) 패턴**: 1~√n까지만 순회하며 약수 쌍을 한 번에 카운트 — `count += 2`, 완전제곱수면 `count -= 1`로 보정. 코테 필수 패턴
- **시간복잡도 사전 점검 습관**: n ≤ 100,000에서 이중 반복(O(n²))은 위험 → 코드 짜기 전에 탐색 범위를 수학적으로 줄일 수 있는지 먼저 확인
- **불필요한 자료구조 제거**: 약수 리스트를 만들어 len()하는 대신 카운트 변수 하나로 충분 — "이 데이터를 저장할 필요가 있나?" 자문하기
- **정수 나눗셈 vs 실수 나눗셈**: 약수 판별은 `%` 연산이면 충분, `/`(float) 대신 `//`나 `%`를 쓰면 빠르고 정확
