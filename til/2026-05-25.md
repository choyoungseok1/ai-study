## 배운 개념
- **이진탐색(Binary Search)**: 정렬된 배열에서 O(log n)으로 탐색하는 알고리즘. `bisect` 모듈의 `bisect_left`/`bisect_right`로 파이썬에서 간편 구현 가능
- **순위검색 문제 접근법**: 쿼리 조건별로 미리 점수 리스트를 정렬해두고, 이진탐색으로 기준 점수 이상인 인원 수를 빠르게 구하는 전략 (완전탐색 → 이진탐색 최적화)
- **CNN 심화 기법들**:
  - BatchNorm: 각 레이어 입력을 정규화하여 학습 안정화 + 학습률을 높일 수 있음
  - Dropout: 학습 시 랜덤하게 뉴런을 끄는 정규화 기법, 과적합 방지
  - 데이터 증강(Data Augmentation): 회전/반전/크롭 등으로 학습 데이터를 인위적으로 늘려 일반화 성능 향상
