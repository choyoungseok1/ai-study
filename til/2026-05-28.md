## 배운 개념
- **DFS + BFS 혼합 전략**: DFS로 선택 경우의 수를 탐색하고, 각 선택마다 BFS로 연쇄 감염을 처리하는 이중 구조. 탐색(DFS)과 시뮬레이션(BFS)의 역할 분리가 핵심
- **가지치기(Pruning)**: `len(next_infected) > len(current_infected)` 조건으로 변화 없는 분기를 스킵. 완전탐색에서 실행 시간을 줄이는 필수 기법
- **nonlocal 키워드**: 중첩 함수에서 바깥 함수의 변수를 수정할 때 사용. `max_infected`를 DFS 재귀 안에서 갱신하기 위해 필요
- **선형 어텐션(Linear Attention)**: softmax 어텐션 대신 과거 정보를 state로 압축해서 넘기는 방식. 메모리 고정 + 추론 비용 O(1)/토큰
- **RWKV의 학습/추론 이중 모드**: 동일한 수식을 학습 시에는 행렬로 펼쳐 병렬 처리, 추론 시에는 RNN으로 순차 처리. 두 장점을 동시에 취하는 설계

## 막힌 부분
- **DFS 최대값 갱신 위치**: `max_infected` 갱신을 종료 조건(rem_k == 0) 안에만 넣으면, k를 다 쓰지 않고도 최대인 경우를 놓침. 갱신은 매 재귀 호출 시작 시 해야 함 → 처음에 종료 조건 안에서만 했다가 수정
- **불필요한 변수 선언 습관**: `infectedn`, `answer` 등 쓰지 않는 변수를 선언해두는 패턴 반복 → 코드 정리 시 사용하지 않는 변수 제거 습관 필요
- **선형 어텐션 수식 이해 부족**: softmax 제거 후 커널 트릭으로 O(n²) → O(n) 달성하는 구체적인 수학적 변환 과정이 아직 불명확
- **State 압축의 정보 손실**: RNN 방식으로 과거를 state에 압축하면 Transformer처럼 모든 토큰을 직접 참조하는 것보다 정보가 손실될 수 있는데, 어떤 태스크에서 이 한계가 두드러지는지 구체적 사례 파악 필요
