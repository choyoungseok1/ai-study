  - 초항 `k`의 우박수열(콜라츠)을 생성하고, 꺾은선 그래프를 구간 `[a, b]`로 정적분(사다리꼴 면적 합)하는 문제.
  - `n`을 "1이 될 때까지의 횟수 = len(seq) - 1"로 정확히 정의하고, 끝점을 `end = n + b`(b ≤ 0)로 계산.
  - 구간별 사다리꼴 면적 `area[i] = (seq[i] + seq[i+1]) / 2`를 미리 쌓아, 질의를 `sum(area[a:end])` 한 줄로 처리.
  - 제출 코드 → 개선 코드로 리팩터링: 죽은 카운터 `i` 제거, 파라미터 `k` 보존(`cur`로 순회 분리), `n = len(area)`로 의미 명시, 삼항 연산자로 분기 압축.
  - 검증: 브루트포스 대조 + 제출/개선/브루트 3-way 랜덤 2,000케이스 대조 + 폭 0·뒤집힌 구간·초항 경계 assert.

## 배운 개념
- **누적 구간합으로 질의를 O(1)~한 줄로**: 사다리꼴 면적을 `area` 리스트로 미리 계산해두면 임의 구간 정적분이 슬라이스 합으로 끝난다. 질의가 많고 구간이 길면 prefix sum(`prefix[end] - prefix[a]`)으로 O(1)까지 확장 가능.
- **경계를 특수처리 대신 구조로 흡수**: 폭 0 구간(`a == end`)은 `area[a:a]`가 빈 슬라이스 → `sum([]) == 0`이 자동으로 나온다. `if`로 예외를 막지 말고 슬라이스 반열림 구조로 예외 자체를 없애는 패턴.
- **prefix sum의 인덱스 가드 제거**: 누적합 앞에 `0`을 하나 깔아두면(`prefix = [0]`) `l=0`에서 `prefix[l-1]` 접근 문제가 사라진다.

## 막힌 부분
- **`[2,-3]`은 0.0인데 `[3,-3]`은 왜 -1인가**: 두 구간의 끝점은 `5-3=2`로 같고, 시작점만 다르다. `[2,2]`는 폭 0(유효, 0.0)이고 `[3,2]`는 `a > end`(뒤집힌 구간, -1). 헷갈린 근본 원인은 "점의 개수(6)"와 "횟수(5)"를 구분하지 못한 것 — `n = len(seq) - 1`이 정답. (len과 횟수 기준 불일치)
- **슬라이스 끝을 `end`(미포함)로 잡는 근거**: x=a~end 구간의 사다리꼴은 인덱스 `a..end-1`이므로 `area[a:end]`가 정확하다. off-by-one이 나기 쉬운 자리.
- **우연히 안 터지는 코드 2개**: (1) 컴프리헨션에서 while의 `i`를 재사용 — Python 3의 컴프리헨션 스코프 분리 덕분에 우연히 안 터짐(Py2였다면 덮어써짐). (2) 파라미터 `k`를 루프에서 소비 — 초항을 다시 안 써서 통과하지만 "변수가 두 역할 겸함"은 위험 패턴. → "왜 안 터지는지 증명이 필요한 구조"는 애초에 만들지 않는 게 정석.
