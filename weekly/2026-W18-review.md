## 못한 것 / 막힌 것

### 반복되는 약점
- **시간복잡도 의식 부족**: 기사단원 무기(O(n²)) / 짝꿍(O(n³)) 문제에서 시간 초과. 코드 짜기 전 입력 크기 보고 허용 복잡도 추정하는 습관 부족
- **인덱스 범위 체크 누락**: 카드뭉치 문제에서 `cards1[i]` 접근 전 `i < len(cards1)` 체크 안 함. 학습 플랜의 "탐색 범위 산정" 패턴 그대로
- **list vs set 구분**: `in` 검색에서 list 쓰면 O(n), set 쓰면 O(1)이라는 감각이 약함

### 새로 인식한 약점
- **표준 라이브러리에 대한 잘못된 인식**: "Counter 같은 라이브러리 안 쓰는 게 진짜 실력"이라고 생각했는데, 표준 라이브러리는 적극 활용하는 게 맞음
- **`dict.setdefault` / `defaultdict` 문법 헷갈림**: 신고 문제에서 syntax error 여러 번
- **문제 조건 정독 부족**: 카드뭉치에서 "순서대로"라는 핵심 제약을 놓치고 `insert()`로 풀려고 함. 짝꿍에서 "개수만 중요"한 문제를 "매칭"으로 풀려고 함
