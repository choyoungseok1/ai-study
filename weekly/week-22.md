## 배운 핵심 3가지

1. **PyTorch 학습 파이프라인 전체 흐름** — 텐서 생성 → Autograd 자동미분 → nn.Module 모델 정의 → 학습 루프 5줄(`zero_grad → 예측 → loss → backward → step`) → 실제 데이터셋(당뇨병/유방암)에 적용까지 일관된 구조로 완주. 표준화(`mean/std`)가 SGD 수렴에 결정적이라는 점을 직접 체감
2. **BFS 최단거리 패턴** — BFS는 레벨 단위 탐색이므로 가중치 없는 그래프에서 먼저 도달 = 최단 경로. `deque 초기화 → popleft → 목적지 체크 → 4방향 탐색 → 조건 확인 → 큐 추가`의 뼈대를 체득. `(r, c, dist)` 튜플로 거리 전달하는 패턴도 익힘
3. **자료구조의 "장점을 살리는" 사용법** — dict를 쓰면서 내부에서 O(N) 순회하면 해시맵 의미 없음(O(N²)). `dict.get(key, 0)+1` 패턴으로 O(N) 한 번에 해결하는 것이 정석. 큐 문제에서도 기준값(polar)을 유지하며 한 번 순회하는 그룹핑 패턴 학습
