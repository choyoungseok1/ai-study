# RWKV: Reinventing RNNs for the Transformer Era
- arxiv: https://arxiv.org/abs/2305.13048
- 날짜: 2026-05-27

## 한 줄 요약
Transformer의 병렬 학습 능력과 RNN의 O(1) 추론 효율성을 결합한 선형 어텐션 기반 아키텍처로, 14B 파라미터까지 스케일링에 성공하며 Transformer의 O(n²) 복잡도 문제를 근본적으로 해결했다.

## 새로 알게 된 것
- **선형 어텐션의 원리**: 기존 어텐션은 모든 토큰 쌍을 비교해서 O(n²)인데, RWKV는 현재 시점에서 과거 정보를 하나의 state로 압축해서 넘기는 방식으로 토큰당 O(1) 처리가 가능하다. 각 토큰의 어텐션을 독립적으로 계산하고 이를 n개로 확장하면 전체 O(n).
- **RWKV의 4가지 핵심 요소**: Receptance(과거 정보 수용 게이팅, LSTM의 gate와 유사), Weight(시간 감쇠, 먼 토큰일수록 영향 감소), Key/Value(Transformer의 K, V와 동일 역할).
- **Token Shift**: 현재 토큰과 이전 토큰을 선형 보간하는 것만으로 순서 정보를 캡처. 별도 위치 임베딩 불필요 → 구조가 단순하고 가벼움.
- **학습/추론 이중 모드**: 동일한 수식을 학습 시에는 행렬로 펼쳐서 병렬 처리(O(n)), 추론 시에는 이전 state만 참조하는 RNN 모드(토큰당 O(1))로 동작. 이게 RWKV의 핵심 혁신.
- **고정 메모리 추론**: Transformer는 생성 길이가 길어질수록 KV 캐시가 쌓여서 메모리가 급증하는데, RWKV는 state 크기가 고정이라 엣지 디바이스나 모바일 환경에서 유리하다.
- **Scaling Law 동일**: 14B까지 스케일업했을 때 Transformer와 동일한 성능 곡선을 보여, 대체 아키텍처로서의 가능성을 증명했다.

## 이해 안 된 것
- Linear Attention에서 구체적으로 어떤 수학적 변환을 통해 O(n²) → O(n)을 달성하는지, 수식 레벨에서의 이해가 부족하다. (softmax를 제거하고 커널 트릭을 사용한다는 정도만 파악)
- 정보 손실 문제: state에 과거 정보를 압축하는 방식이니 Transformer처럼 모든 토큰을 직접 참조하는 것보다 정보가 손실될 수 있는데, 실제로 어떤 태스크에서 이 한계가 두드러지는지 구체적인 사례를 모르겠다.

## 한계점
- RNN의 hidden state 방식을 활용하므로 정보를 지속적으로 압축/누적하는 과정에서 정보 손실 가능성이 존재한다.
- 같은 자원에서 Transformer보다 유리하지만, 소형 모델이라도 스마트폰 CPU만으로 구동하기에는 아직 한계가 있다.
