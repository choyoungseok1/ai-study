## 1. How to Avoid Machine Learning Pitfalls: A Guide for Academic Researchers

**arxiv**: [https://arxiv.org/abs/2108.02497](https://arxiv.org/abs/2108.02497)
**발표일**: 2021년 8월 (2026년 v5 업데이트)
**페이지**: 약 13페이지
**코드**: 없음 (가이드 문서 형식)

### 초록 요약
머신러닝 프로젝트에서 흔히 저지르는 실수들을 5단계로 정리한 실전 가이드. (1) 모델 구축 전 준비, (2) 신뢰할 수 있는 모델 구축, (3) 견고한 모델 평가, (4) 공정한 모델 비교, (5) 결과 보고까지, 각 단계별 주의사항과 해결책을 체계적으로 제시한다.

### 추천 이유
1. 지금 배우고 있는 train/test 분리, StandardScaler 적용 순서, 과적합 판별 등의 개념이 "왜 그렇게 해야 하는지" 실수 사례와 함께 설명되어, 혼공머신러닝의 이론을 실전 감각으로 연결해준다.
2. 코드 없이 13페이지 읽기 자료라 부담이 적고, ML 면접에서 자주 나오는 "데이터 누출(data leakage)", "교차 검증(cross-validation)" 개념을 한 번에 정리할 수 있다.
3. 5/9 TIL에서 배운 "fit은 train에만, transform은 train/test 둘 다"가 바로 이 논문의 핵심 함정 중 하나 — 이미 체험한 개념을 이론적으로 보강할 수 있다.

## 2. Tabular Data: Deep Learning is Not All You Need

**arxiv**: [https://arxiv.org/abs/2106.03253](https://arxiv.org/abs/2106.03253)
**발표일**: 2021년 6월 (ICLR 2022)
**페이지**: 약 8페이지 (본문) + 부록
**코드**: ✅ [https://github.com/ravid-shwartz-ziv/tabular-dl-not-all-you-need](https://github.com/ravid-shwartz-ziv/tabular-dl-not-all-you-need)

### 초록 요약
11개 데이터셋에서 딥러닝 모델(TabNet, NODE 등)과 전통 ML 모델(XGBoost)을 체계적으로 비교한 논문. 결론: XGBoost가 대부분의 테이블 데이터에서 딥러닝을 이기거나 비슷한 성능을 보이며, 하이퍼파라미터 튜닝도 훨씬 쉽다. 앙상블(XGBoost + 딥러닝)이 가장 좋은 성능을 보인다.

### 추천 이유
1. 지금 scikit-learn으로 회귀/분류를 배우면서 "딥러닝을 안 배워도 되나?" 하는 의문이 생길 수 있는데, 이 논문이 "전통 ML이 테이블 데이터에서는 여전히 강력하다"는 것을 데이터로 증명해준다.
2. 곧 혼공머신러닝에서 결정 트리 → 랜덤 포레스트 → 그래디언트 부스팅으로 넘어갈 텐데, XGBoost가 왜 중요한지 미리 감을 잡을 수 있다.
3. 코드가 공개되어 있고, 실험 설계(데이터셋 선정 → 하이퍼파라미터 튜닝 → 성능 비교)를 따라가면 ML 실험 파이프라인의 전체 그림을 익힐 수 있다.

## 3. Don't Waste Bits! Adaptive KV-Cache Quantization for Lightweight On-Device LLMs

**arxiv**: [https://arxiv.org/abs/2604.04722](https://arxiv.org/abs/2604.04722)
**발표일**: 2026년 4월 6일 (CVPR 2026 Accepted)
**페이지**: 약 10페이지 (본문)
**코드**: 미공개 (단, 실험 재현 가능한 상세한 설정 포함)

### 초록 요약
LLM 추론 시 KV 캐시의 비트 폭을 토큰 중요도에 따라 동적으로 할당(2-bit/4-bit/8-bit/FP16)하는 적응형 양자화 프레임워크. 토큰 빈도, 품질 점수, 어텐션 분산, 엔트로피 기반 불확실성 등 경량 특성을 추출하여 컨트롤러가 실시간으로 정밀도를 선택한다. SmolLM-360M에서 디코딩 지연 17.75% 감소, 정확도 7.60점 향상을 달성했다.

### 추천 이유
1. Week 3 회고에서 "다음 논문 후보"로 직접 언급한 논문 — 학습 동기가 이미 확보되어 있다.
2. 이전에 리뷰한 Transformer 논문(KV Cache, GQA)의 자연스러운 후속 독해로, Attention → KV Cache → 양자화 최적화까지 기술 계보를 이어갈 수 있다.
3. "토큰 중요도에 따라 비트를 다르게 배분"한다는 핵심 아이디어는 허프만 코딩에서 영감을 받았고, 이는 데이터 압축의 기본 원리를 LLM에 적용한 것이라 개념적으로 접근하기 쉽다.

## 4. Model Evaluation, Model Selection, and Algorithm Selection in Machine Learning

**arxiv**: [https://arxiv.org/abs/1811.12808](https://arxiv.org/abs/1811.12808)
**저자**: Sebastian Raschka (Python Machine Learning 저자)
**발표일**: 2018년 11월 (2020년 v3 업데이트)
**페이지**: 약 15페이지 (각 파트별 독립 읽기 가능)
**코드**: ✅ [https://github.com/rasbt/model-eval-article-supplementary](https://github.com/rasbt/model-eval-article-supplementary)

### 초록 요약
머신러닝에서 모델 평가와 선택을 위한 통계적 기법을 체계적으로 정리한 논문. Holdout, k-Fold Cross-Validation, Bootstrap, Nested Cross-Validation 등 평가 기법의 원리와 편향-분산 트레이드오프, 그리고 모델 간 통계적 비교(McNemar, 5x2cv paired t-test) 방법까지 다룬다.

### 추천 이유
1. 혼공머신러닝에서 곧 나올 교차 검증(cross-validation), 하이퍼파라미터 튜닝 개념의 이론적 배경을 미리 탄탄하게 잡을 수 있다.
2. Python Machine Learning 저자 Sebastian Raschka가 쓴 논문이라 설명이 매우 친절하고, scikit-learn 코드 예제가 함께 제공된다.
3. "Ridge에서 alpha를 어떻게 고르나?" (5/9 TIL에서 연습한 내용)의 체계적 답변이 이 논문에 있다 — 경험적 튜닝을 넘어 이론적 근거를 갖추게 된다.
