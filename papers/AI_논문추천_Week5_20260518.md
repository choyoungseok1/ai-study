## 논문 1

### A Comparative Study of Machine Learning and Deep Learning for Out-of-Distribution Detection

**저자:** Jihyeon Baek, Seunghoon Lee, Gitaek Kwon, Doohyun Park
**날짜:** 2026-05-11
**arXiv:** [https://arxiv.org/abs/2605.10181](https://arxiv.org/abs/2605.10181)

**초록:**
OOD(Out-of-Distribution) 탐지는 신뢰할 수 있는 AI 시스템 구축에 필수적입니다. 딥러닝이 전통적 머신러닝보다 우수하다고 흔히 가정하지만, 이 논문은 의료 영상 분야에서 두 접근법을 직접 비교합니다. 60,000장 이상의 안저 영상 데이터에서 ML과 DL 모두 AUROC 1.000을 달성했으나, ML 접근법이 훨씬 낮은 지연시간으로 동등한 정확도를 유지했습니다.

**추천 이유:**
1. 현재 공부 중인 전통적 ML(결정트리, 앙상블)과 DL을 직접 비교하는 논문으로, 두 접근법의 장단점을 체감할 수 있음
2. OOD Detection이라는 실무에서 중요한 개념을 자연스럽게 학습할 수 있음
3. 2026년 5월 최신 논문이며, 실험 설계가 깔끔하여 논문 읽기 입문용으로 적합

**코드:** 논문 내 실험 코드 확인 필요
**한글 참고:** [Knowledge Distillation 해설 블로그](https://baeseongsu.github.io/posts/knowledge-distillation/)

## 논문 2

### Learning Rate Matters: Vanilla LoRA May Suffice for LLM Fine-tuning

**저자:** Yu-Ang Lee, Ching-Yun Ko, Pin-Yu Chen, Mi-Yen Yeh
**날짜:** 2026-02-04
**arXiv:** [https://arxiv.org/abs/2602.04998](https://arxiv.org/abs/2602.04998)

**초록:**
LoRA(Low-Rank Adaptation)는 LLM 효율적 파인튜닝의 대표적 방법입니다. 최근 다양한 LoRA 변형이 제안되었지만, 이 논문은 4개의 대표적 LoRA 변형과 기본 LoRA를 광범위한 하이퍼파라미터 탐색을 통해 재평가합니다. 핵심 발견: 학습률(Learning Rate)만 제대로 튜닝하면 모든 방법이 1~2% 이내의 유사한 성능을 달성합니다.

**추천 이유:**
1. SGD와 학습률을 공부한 직후라, Learning Rate의 중요성을 LLM 맥락에서 재확인할 수 있는 최적의 타이밍
2. LoRA라는 현업 필수 개념을 처음 접하기에 좋은 논문 (Low-Rank = 행렬 분해 기초)
3. 실험 중심 논문으로 복잡한 수학 없이도 핵심 메시지를 이해할 수 있음

**코드:** [HuggingFace Paper Page](https://huggingface.co/papers/2602.04998)
**한글 참고:** [LoRA 논문 한글 해설](https://ffighting.net/deep-learning-paper-review/language-model/lora/)

## 논문 3

### How LLMs Are Persuaded: A Few Attention Heads, Rerouted

**저자:** Xiangkun Sun et al.
**날짜:** 2026-05-10
**arXiv:** [https://arxiv.org/abs/2605.09314](https://arxiv.org/abs/2605.09314)

**초록:**
소수의 중간 레이어 어텐션 헤드가 모델의 답변을 거의 전적으로 결정합니다. 이 헤드들은 답변 옵션을 저차원 다면체의 꼭짓점에 매핑하며, 설득(persuasion)은 올바른 답변 꼭짓점에서 설득 대상 꼭짓점으로의 이산적 잠재 점프를 유발합니다. 연구진은 rank-one evidence-routing feature를 분리하여, 이를 직접 수정하면 모델의 선택을 조종할 수 있고 제거하면 설득을 차단할 수 있음을 보였습니다.

**추천 이유:**
1. Transformer 프로젝트(한영 번역)를 수행한 경험이 있어, Attention 메커니즘의 내부 작동을 더 깊이 이해할 수 있음
2. LLM의 의사결정 과정을 해부학적으로 분석한 최신(2026.05) 논문
3. Mechanistic Interpretability라는 최신 연구 트렌드를 맛볼 수 있는 흥미로운 주제

**코드:** 논문 내 확인 필요
**한글 참고:** [Transformer(Attention is All You Need) 논문 분석 및 코드 실습](https://happy-jihye.github.io/nlp/nlp-8/)

## 논문 4

### Gradient Boosting Decision Tree with LSTM for Investment Prediction

**저자:** Chang Yu, Fang Liu, Jie Zhu, Shaobo Guo et al.
**날짜:** 2025-05-29
**arXiv:** [https://arxiv.org/abs/2505.23084](https://arxiv.org/abs/2505.23084)

**초록:**
LSTM 네트워크와 LightGBM, CatBoost를 결합한 하이브리드 프레임워크를 제안합니다. ANN, CNN, BiLSTM, LSTM, XGBoost, LightGBM, NN 등 7개 모델을 평가하며, 하이브리드 프레임워크가 개별 모델 대비 10~15% 정확도 향상을 달성하고 시장 변동 시 오류를 줄였습니다.

**추천 이유:**
1. 현재 공부 중인 결정트리/앙상블(XGBoost, LightGBM, CatBoost)과 딥러닝(LSTM)을 결합하는 실전적 접근법
2. 7개 모델을 체계적으로 비교하여, ML vs DL 성능 차이를 직관적으로 이해할 수 있음
3. 금융 예측이라는 구체적 응용 사례로 모델 선택의 실무적 감각을 기를 수 있음

**코드:** 논문 내 확인 필요
**한글 참고:** XGBoost/Gradient Boosting 관련 한글 자료 검색 추천

## 논문 5

### Beyond LoRA vs. Full Fine-Tuning: Gradient-Guided Optimizer Routing for LLM Adaptation

**저자:** arXiv 2605.07111
**날짜:** 2026-05-08
**arXiv:** [https://arxiv.org/abs/2605.07111](https://arxiv.org/abs/2605.07111)

**초록:**
LoRA와 Full Fine-Tuning 사이의 이분법을 넘어, MoLF(Mixture of LoRA and Full Fine-Tuning)라는 통합 프레임워크를 제안합니다. Gradient 기반으로 각 파라미터에 대해 LoRA와 Full FT 중 최적의 업데이트 방식을 자동 라우팅하여, 두 방식의 장점을 동시에 취합니다.

**추천 이유:**
1. SGD/Gradient 개념을 실제 LLM 학습에 어떻게 활용하는지 보여주는 최신 논문(2026.05)
2. LoRA 논문(#2)을 읽은 후 후속으로 읽으면 파인튜닝 전반에 대한 이해가 깊어짐
3. Optimizer Routing이라는 새로운 개념으로 최적화 이론의 실전 응용을 체험할 수 있음

**코드:** 논문 내 확인 필요
**한글 참고:** [LoRA 논문 리뷰 (김지영 블로그)](https://kimjy99.github.io/%EB%85%BC%EB%AC%B8%EB%A6%AC%EB%B7%B0/lora/)
