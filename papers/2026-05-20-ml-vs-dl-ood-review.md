# A Comparative Study of Machine Learning and Deep Learning for Out-of-Distribution Detection
- arxiv: https://arxiv.org/abs/2605.10181
- 날짜: 2026-05-20

## 한 줄 요약
의료 영상 OOD 탐지에서 ML(ExtraTrees)이 DL(ResNet-18)과 동등한 성능을 내면서 최대 6배 빠른 속도를 달성 — 단순한 이진 분류 태스크에서는 DL의 복잡성이 불필요할 수 있다.

## 섹션별 요약

### Introduction
- OOD 탐지는 신뢰할 수 있는 AI 시스템에 필수 (특히 의료처럼 안전이 중요한 분야)
- 기존 연구는 대부분 DL 기반 → 높은 연산 비용
- 의료 영상은 표준화된 조건에서 촬영되어 변동이 적으므로, ML로도 충분할 수 있다는 가설 → 이걸 검증하는 게 이 논문의 목적

### Methods
- 6만장 이상의 의료 이미지를 IV(학습+내부 평가)와 EV(외부 테스트) 세트로 분리
- ML: 원본 이미지에서 39개 수작업 피처 추출 → ExtraTrees 분류기 학습, SHAP으로 피처 기여도 해석
- DL: ResNet-18 사전학습 모델을 파인튜닝, center crop + 정규화 + 데이터 증강 적용, Grad-CAM++로 시각적 해석
- 두 파이프라인 모두 여러 해상도(1×, 1/2×, 1/4×, 1/8×)에서 성능과 속도를 비교

### Results
- ML과 DL 모두 AUROC 1.000, 정확도 0.995 이상으로 성능은 거의 동일
- ML은 해상도 낮출수록 속도가 급격히 개선(396ms → 31ms), 성능은 유지
- DL은 해상도와 무관하게 속도가 일정(183~229ms) — 고정 비용이 지배적
- ML이 DL 대비 최대 6배 빠르면서 동등한 성능 달성

### Discussion
- 성능이 동등하면 모델 선택 기준은 정확도가 아니라 속도, 메모리, 해석 가능성이 된다
- ML은 SHAP으로 "왜 이렇게 판단했는지" 투명하게 설명 가능, DL의 Grad-CAM++은 이 태스크에서 해석력이 떨어짐
- 실전 제안: ML로 OOD 필터링(입구에서 거르기) → DL은 진짜 진단에만 집중하는 2단계 구조가 효율적
- 한계: 스마트폰 촬영 같은 비표준 환경은 검증 안 됨, 다른 의료 도메인에 적용하려면 피처 재설계 필요

## 새로 알게 된 것
- OOD 탐지라는 개념: 모델이 학습하지 않은 데이터가 들어왔을 때 걸러내는 것의 중요성
- ExtraTrees: 결정트리의 앙상블 버전으로, sklearn에서 바로 사용 가능
- SHAP: 각 피처가 모델 판단에 얼마나 기여했는지 정량적으로 설명하는 해석 도구
- 모델 선택은 정확도만이 아니라 속도, 해석 가능성, 배포 환경까지 고려해야 한다는 실전적 관점
- DL의 속도 병목은 이미지 크기가 아니라 모델 로딩/메모리 같은 고정 비용이 지배적일 수 있다

## 이해 안 된 것 / 처음에 잘못 이해한 것
- Results에서 "해상도 높으면 DL 유리, 낮으면 ML 유리"라고 생각했으나 → 실제로는 성능은 둘 다 동등하고, 차이는 속도에서만 발생. DL의 병목은 이미지 크기가 아니라 모델 로딩/메모리 같은 고정 비용
